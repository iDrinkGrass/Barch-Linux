# Barch Linux :D
Hello, I made a WebOS for the Hack Club Stardance challenge. Barch Linux is basically a rip off Arch Linux, but on the web. Sadly, the end of the project was kind of rushed because I had a trip to the Philippines in a couple of days :( But I hope you enjoy what I've made.

## Features

* Draggable and Closeable/Openable Windows
* Welcome Window
* Terminal App (Somewhat functional)
* Functional Clock and Date
* Links Window

## Notes

* Try typing something in the terminal and pressing enter.
* To open the welcome page, press the button that says “Barch Linux Welcome!” at the top right corner.
* To close windows, press the X button at the top right corner of the window.
* To reopen the Terminal, press the Terminal icon.
